# YoLingo — Website Files

A static French-language school website with no CMS or admin login.

## Pages
- `index.html` — homepage featuring the original Yo mascot
- `pricing.html` — course plans and pricing
- `contact.html` — contact form (Formspree, original endpoint retained)
- `thank-you.html`, `privacy.html`, `terms.html`, `refund-policy.html`

## Preview
Open `preview.html` in your browser to explore the pages and switch between desktop and mobile previews. This preview is standalone and disables actual form submissions.

## Publish
Upload the website files to your static host (Netlify or equivalent). For the live form to work, verify the existing Formspree endpoint and domain. There is no admin page, Netlify Identity, or CMS in this version. To edit page text, edit the HTML files directly.
